WHEN HTML BECOMES A DECK

替代不是“更炫”，而是更完整

只要播放、编辑、素材、输出四件事都闭环，HTML 就不再只是网页。

PLAY

像 PPT 一样播放

固定画幅、翻页、进度、触控。

EDIT

像设计稿一样改

文字、图片、位置、动效都可调。

MEDIA

像网页一样承载

图表、视频、代码、交互都原生。

SHIP

像链接一样分发

本地文件夹、PDF、URL 都可用。

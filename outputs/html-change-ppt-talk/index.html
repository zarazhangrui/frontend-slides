CORE THESIS

PPT 是页面；
HTML 是运行时

传统 PPT 把表达压缩进一页页静态画布；HTML 把表达放回浏览器运行时。区别不只是“更炫”，而是演讲者可以把状态、逻辑、输入和传播都纳入演讲。

不是所有演讲都需要 HTML

TRADEOFFS MATTER

简单汇报

如果目标只是稳定传达文字和图表，传统 PPT 或 PDF 仍然足够。

现场稳定

HTML 需要提前测试浏览器、离线策略、字体加载和投影比例。

维护成本

一旦引入代码，就要把内容当成产品：版本、兼容、复用都要管理。

真正的判断标准不是“能不能做得更酷”，而是这场演讲是否需要运行时能力来让观点更清楚。

编辑器使用介绍

打开和选择

按 E 或点左上角按钮进入编辑。点选画面里的文字、图片、背景图或视觉块后，右侧面板会显示可编辑属性。

内容和图片

  • 文字在右侧 Content 区修改，双击文字会自动聚焦到文字输入框。
  • 拖入图片到画面可新增图片；选中图片后拖入或选择文件会替换它。
  • 未标记的普通 HTML 也会自动识别常见文本、图片、背景图、SVG/canvas 和有边框/背景的视觉块。

布局和样式

拖动选框移动元素，拖右下角改变尺寸；右侧 Layout 可以精确输入位置和大小。拖动时会出现对齐参考线，方便和画面中心或其他元素吸附。

动效和保存

  • Motion 区可以设置入场方式、出现顺序、延迟和时长，并支持预览当前元素或重播本页。
  • 撤回用 ↶ 或 Cmd/Ctrl+Z；重做用 ↷ 或 Cmd/Ctrl+Shift+Z。
  • 保存到本地会下载当前 index.html，并清理选框、临时检测标记和编辑器界面。
